# О проекте

RadSafe Trainer — это современный тренажер для подготовки специалистов Республики Казахстан к аттестации по радиационной безопасности.

Проект создается с целью предоставить удобный инструмент для самостоятельной подготовки, проверки знаний и повторения вопросов перед официальной аттестацией.

Основная задача проекта — сделать подготовку простой, удобной и максимально приближенной к реальному тестированию.

---

# Основные возможности

- Подготовка к аттестации
- Пробное тестирование
- Режим обучения
- Работа над ошибками
- Личная статистика
- Случайные вопросы
- Выбор тем
- Повтор сложных вопросов

# Платформы

В дальнейшем планируется создание:
