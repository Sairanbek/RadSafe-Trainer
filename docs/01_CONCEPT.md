# RST — Radiation Safety Trainer

## Версия документа
0.1

---

# 1. Цель проекта

Создать единую платформу для подготовки специалистов к аттестации в области радиационной безопасности и смежных направлений.

RST должен стать современным инструментом обучения, подготовки и проверки знаний.

---

# 2. Почему появился проект

На сегодняшний день подготовка к аттестации имеет ряд недостатков:

- неудобный процесс обучения;
- отсутствует качественный тренажер;
- сложно анализировать ошибки;
- отсутствует персональная статистика;
- отсутствует интеллектуальный помощник.

RST должен решить эти проблемы.

---

# 3. Миссия

Повысить качество подготовки специалистов, работающих с источниками ионизирующего излучения.

---

# 4. Основные пользователи

- специалисты по радиационной безопасности;
- дозиметристы;
- инженеры;
- медицинские физики;
- специалисты КТ;
- специалисты рентгенологии;
- специалисты ядерной медицины;
- студенты профильных специальностей.

---

# 5. Первая версия продукта

Первая версия должна позволять:

- регистрацию пользователя;
- прохождение тестов;
- просмотр результатов;
- анализ ошибок;
- повторное прохождение тестов.

---

# 6. Долгосрочная цель

Создать крупнейшую русскоязычную платформу подготовки специалистов по радиационной безопасности и смежным направлениям.
