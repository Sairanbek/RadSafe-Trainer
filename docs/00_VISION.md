# RST — Vision

## Что такое RST?

RST — это единая образовательная платформа для подготовки специалистов к аттестации и повышению квалификации.

RST не является просто Telegram-ботом.

RST — это экосистема обучения.

---

# Главная цель

Сделать обучение настолько удобным, чтобы человек мог подготовиться к экзамену полностью с телефона.
