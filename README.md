# О проекте

RadSafe Trainer (RST) — тренажёр для подготовки специалистов Республики Казахстан к аттестации
по радиационной безопасности.

Проект даёт удобный инструмент для самостоятельной подготовки, проверки знаний и повторения
вопросов перед официальной аттестацией — максимально приближенный к реальному тестированию.

Банк вопросов — **436 вопросов в 16 разделах** с подразделами, составлен по нормативным
документам РК (первоисточники на [adilet.zan.kz](https://adilet.zan.kz)).

# Возможности

## Режимы тестирования

- **Тренировка** — по разделу или подразделу, без ограничения времени; длина сессии зависит от
  размера раздела.
- **Аттестация** — все разделы, 50 вопросов, 75 минут, порог сдачи 70 %.
- **Работа над ошибками** — повтор только тех вопросов, где были ошибки.
- **Обучение** — правильный ответ виден сразу, без баллов, не пишется в статистику и историю
  (сайт и мобильное приложение).

## Общее для всех клиентов

- ✅ Перемешивание вариантов ответа, проверка сразу после выбора
- ✅ Личная статистика по разделам — видно слабые места
- ✅ История прохождений
- ✅ Итоговая сводка после теста (процент, сдал / не сдал)
- ✅ ИИ-ассистент на Google Gemini: разбор вопроса, свободный чат по радиационной безопасности,
  персональный план обучения по вашей статистике

## Сайт и мобильное приложение

- ✅ Регистрация по email с подтверждением адреса, восстановление пароля по письму
- ✅ Личный кабинет: смена имени и пароля, согласие на передачу данных ИИ
- ✅ Состояние теста хранится в базе — сессия переживает перезапуск сервера и смену устройства
- ✅ Короткий access-токен (1 час) + отзываемый refresh-токен на 30 дней с ротацией
- ✅ Rate limiting на auth- и AI-эндпоинтах, security-заголовки, политика конфиденциальности

## Только сайт

- ✅ Админ-панель: добавление, правка и удаление вопросов (в мобильное не портирована)

## Только Telegram-бот

- ✅ Админ-функции и импорт вопросов из Excel

# Эксплуатация и автоматизация

- **Развёртывание** — Docker Compose: backend, собранный фронтенд за Caddy с авто-HTTPS и
  Telegram-бот. Инструкция: [DEPLOY.md](DEPLOY.md).
- **Локальный запуск** для разработки: [RUNBOOK.md](RUNBOOK.md).
- **Бэкапы** базы сайта (`scripts/backup_db.py`, 14 последних снимков).
- **Автоперегенерация неверных вариантов ответа** через Gemini небольшими порциями
  (`scripts/regenerate_distractors.py`, `daily_distractor_job.py`).
- **Сверка формулировок с первоисточниками** на adilet.zan.kz (`scripts/scrape_adilet.py`) —
  скрипт только готовит отчёт для человека и никогда не правит вопросы сам: юридическая
  точность требует ручного контроля.
- **Порядок действий при утечке персональных данных** (сроки уведомления по правилам РК):
  [SECURITY_INCIDENT.md](SECURITY_INCIDENT.md).

# Технологии

- **Telegram-бот** — Python, aiogram, сырой `sqlite3`
- **Backend сайта** — FastAPI, SQLAlchemy 2.0, SQLite, JWT
- **Frontend сайта** — React, TypeScript, Vite, React Router
- **Мобильное приложение** — React Native, Expo SDK 57, React Navigation, expo-secure-store
- **ИИ** — Google Gemini (`gemini-flash-latest`)
- **Инфраструктура** — Docker Compose, Caddy (авто-HTTPS от Let's Encrypt)

Бот и backend сайта — **две независимые реализации** одной предметной логики, а не общий код.
Подробнее об архитектуре: [CLAUDE.md](CLAUDE.md).
