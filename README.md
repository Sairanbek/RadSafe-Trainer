# О проекте

RadSafe Trainer — тренажёр для подготовки специалистов Республики Казахстан к аттестации по радиационной безопасности.

Проект создаётся, чтобы дать удобный инструмент для самостоятельной подготовки, проверки знаний и повторения вопросов перед официальной аттестацией — максимально приближенный к реальному тестированию.

---

# Возможности

**Уже работает:**
- ✅ Пробное тестирование — сессии по 50 вопросов
- ✅ Выбор раздела (тема) или прохождение по всем сразу
- ✅ Проверка ответа сразу после выбора, с показом правильного варианта
- ✅ Работа над ошибками — отдельный режим повтора вопросов, где были ошибки
- ✅ Личная статистика по разделам — видно, где слабее места
- ✅ Итоговая сводка после теста (процент, сдал/не сдал)

- ✅ История прохождений между сессиями
- ✅ Подразделы внутри разделов

**В планах:**
- ⬜ Режим обучения (без экзамена — сразу видно объяснение)
- ⬜ Личный кабинет / рейтинг
